# Sources and licences

The module texts in `content/modules.json` are original drafts. They are written from techniques shared by evidence-based parent training programmes, not copied from any programme's materials. Techniques can't be copyrighted; wording can.

## Evidence base used

- Kaminski, Valle, Filene & Boyle (2008). A meta-analytic review of components associated with parent training program effectiveness. J Abnorm Child Psychol 36(4):567–589. Largest effects: positive parent–child interaction and emotional communication, time-out, parenting consistency, practising skills with the child. https://pubmed.ncbi.nlm.nih.gov/18205039/
- WHO/UNICEF Parenting for Lifelong Health (PLH): structure and order of skills (relationship before discipline). https://www.who.int/teams/social-determinants-of-health/parenting-for-lifelong-health
- CDC Essentials for Parenting (communication, structure and rules, directions, consequences, time-out). https://www.cdc.gov/parents/essentials/index.html
- NICE NG87 (ADHD): parent training recommendations and the note that some parents also have ADHD. https://www.nice.org.uk/guidance/ng87
